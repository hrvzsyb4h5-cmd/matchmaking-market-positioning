# 相亲市场定位测试 · 高级版

25项指标四维评分模型 + 理想型匹配模拟器

## 功能

- 性别差异化权重算法(男女不同权重曲线)
- 非线性峰值曲线评分(年龄/身高)
- 四维市场定位(硬件/软实力/家庭/市场供需)
- 25项测评指标,一次一题沉浸式答题
- 理想型匹配模拟器(输入理想型条件看匹配度)
- 雷达图可视化 + 全项得分明细
- 暖粉色调轻松视觉风格

## 技术栈

- 纯 HTML/CSS/JavaScript(无构建步骤)
- ECharts 5.5 数据可视化(CDN)
- Google Fonts: Crimson Pro / Outfit / Geist Mono(CDN)

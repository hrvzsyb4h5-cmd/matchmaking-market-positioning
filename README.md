# 相亲定位与择偶偏好分析

面向相亲个人的自我梳理工具，保留暖粉色视觉和逐题填写体验。

## 功能

- 16 个可跳过的问题，梳理日常生活、相处习惯、家庭安排与关系期待。
- 报告列出原始回答、对应解读与具体行动，不计算人的价值分数、排名或成功概率。
- 择偶条件探索：年龄/身高范围、学历与院校分开、生育、居住、定居、开支与联系频率。
- 条件可分类为必须满足、比较看重、可以商量或暂未分类；默认不替用户设定条件。
- 可编辑自我介绍、见面沟通清单、两周行动清单。
- 下载 UTF-8 文字报告，或用浏览器打印保存 PDF。
- 虚构样例与用户结果有明确区分。

## 数据处理

回答只在当前页面内存中处理，不上传、不写入浏览器存储，刷新即清空。
无第三方脚本、字体或图表依赖。下载的报告包含用户选择填写的内容，请自行保管。

## 本地运行与验证

直接打开 `index.html`。无需安装依赖或构建。
安装 Node.js 后运行 `node tests/report.test.cjs` 检查报告规则与条件校验。
